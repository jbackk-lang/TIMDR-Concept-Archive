0. PĘD (fundament istnienia)
Czysta zmiana bez kierunku.

Nie wymaga przestrzeni, czasu, materii ani informacji.

Jest absolutnym początkiem — „możliwością istnienia”.

Pęd jest generatorem przesunięć → z pędu wyłania się przestrzeń.

1. PROCES (różnicowanie pędu)
Pęd, który zaczyna mieć sekwencję.

Pierwsza forma „dziania się”.

Proces = uporządkowana zmiana.

Proces → generuje czas (czas = kolejność zmian).

2. SKRĘT (orientacja procesu)
Pęd, który nabiera kierunku.

Minimalna asymetria.

Najmniejszy możliwy byt informacji.

Skręt jest pierwszą formą pędu, która może się zapisać.

Skręt → generuje geometrię (spin, helicity, torsion).

3. RELACJA (różnica skrętów)
Powstaje dopiero z procesu + skrętu.

Relacja nie jest fundamentem — jest skutkiem.

Relacja = lokalna struktura przestrzeni (metryka, krzywizna).

Relacja → organizuje przestrzeń.

4. INFORMACJA (zapis relacji)
Informacja = skręt zapisany w procesie.

Informacja = stabilna różnica.

Informacja = struktura pola.

Informacja → utrwala geometrię.

5. CZAS (ślad informacji)
Czas nie jest fundamentem.

Czas jest produktem: śladem zapisów informacji.

Czas = kierunek wzrostu informacji.

Czas → jest historią skrętu.

🜁 ZASADA FUNDAMENTALNA
Skręt jest najmniejszym bytem informacji.
Wyprostowany skręt daje czysty pęd.
Skręt jest pierwszą formą istnienia,
informacja jest pierwszą formą pamięci,
czas jest pierwszą formą historii.

🜄 IMPLIKACJE DLA TOPOLOGII INFORMACJI
Pęd jest warstwą Λ (źródło istnienia).

Proces i skręt tworzą τ (topologiczną dwójkę).

Relacja i informacja tworzą ρ (strukturę zapisu).

Czas jest śladem ρ → nie jest fundamentem, lecz wynikiem.
