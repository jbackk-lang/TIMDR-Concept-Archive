# Zastosowanie: Analiza tekstu (Topologia Informacji 2.1)

## Cel
Użyć jednostek I, S, T, Tw, ΔS, ρ, φ do analizy tekstu:
- wykrywania różnic znaczeniowych,
- przeciążenia informacji,
- stabilności kontekstu.

## Procedura

1. **Wejście jako informacja**
   - Tekst = I.
   - Każde zdanie traktujemy jako osobne Iₖ.

2. **Kształt semantyczny**
   - Embedding zdania → Sₖ.
   - Iₖ → Sₖ (R2).

3. **Transformacja kontekstu**
   - Zmiana tematu, tonu, perspektywy → T(I, Λ).
   - Duża Λ → zmiana klasy topologicznej (R8).

4. **Skręt lokalny**
   - Ironia, dwuznaczność, metafora → Tw(I, Λ).
   - Zmiana orientacji znaczenia bez zmiany słów.

5. **Różnica kształtu ΔS**
   - ΔS(S₁, S₂) mierzy różnicę między dwoma zdaniami.
   - Jeśli |ρ₁ – ρ₂| > ρ* → aktywacja ΔS (warunek stabilności).

6. **Gęstość ρ**
   - ρ rośnie, gdy:
     - dużo pojęć w jednym zdaniu,
     - dużo referencji,
     - dużo skrótów.
   - Wysokie ρ → ryzyko przeciążenia odbiorcy.

7. **Sprzężenie zwrotne φ**
   - φ(Sₜ) → Iₜ₊₁:
     - reakcja odbiorcy,
     - zmiana tonu,
     - korekta wypowiedzi.

## Przykład

- Zdanie A: proste, jasne → niskie ρ, stabilne S↻.
- Zdanie B: przeładowane terminami → wysokie ρ, ryzyko S↺.
- ΔS(A, B) pokazuje, jak bardzo odbiorca musi „przeskoczyć” kształt.
