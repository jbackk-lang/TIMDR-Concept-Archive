# Zastosowanie: Topologia semantyczna (Semantic Topology)

## Cel
Użyć topologii informacji do:
- opisu przestrzeni znaczeń,
- trajektorii pojęć,
- rezonansu między ideami.

## Jednostki

- I — pojęcie / akt znaczenia.
- S — kształt semantyczny (trajektoria pojęcia).
- T — globalna zmiana znaczenia.
- Tw — lokalny skręt (np. ironia).
- ΔS — różnica znaczeń.
- R — rezonans między pojęciami.
- ρ — gęstość znaczeń w jednym obszarze.

## Procedura

1. **Mapa pojęć**
   - każde pojęcie = I,
   - jego kontekst = S.

2. **Transformacje**
   - zmiana definicji → T(I, Λ),
   - zmiana użycia (np. slang) → Tw.

3. **ΔS**
   - ΔS(stare znaczenie, nowe znaczenie) mierzy „przeskok”.

4. **Rezonans R**
   - R(S₁, S₂) mierzy zgodność rytmów znaczeń:
     - metafory,
     - analogie,
     - podobieństwa.

5. **Gęstość ρ**
   - zbyt wiele znaczeń w jednym słowie → wysokie ρ,
   - ryzyko nieporozumień.

## Przykład

- Słowo „filtr”:
  - techniczne,
  - topologiczne,
  - metaforyczne („sprężynka”).
- ρ rośnie, gdy wszystkie znaczenia są aktywne naraz.
