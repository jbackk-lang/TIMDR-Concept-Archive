# Zastosowanie: Podejmowanie decyzji (Decision Topology)

## Cel
Użyć topologii informacji do:
- analizy wyborów,
- redukcji przeciążenia decyzyjnego,
- stabilizacji trajektorii myślenia.

## Jednostki
- I — opcja decyzyjna,
- S — kształt konsekwencji,
- ΔS — różnica między opcjami,
- ρ — gęstość informacji o wyborze,
- N — napięcie decyzyjne,
- φ — korekta po decyzji.

## Procedura

1. **Opcje jako I**
   - Każda decyzja = Iₖ.

2. **Konsekwencje jako S**
   - Sₖ = przewidywany kształt skutków.

3. **ΔS**
   - ΔS(S₁, S₂) pokazuje, jak bardzo różnią się konsekwencje.

4. **ρ**
   - Zbyt dużo danych → wysokie ρ → paraliż decyzyjny.

5. **Stabilizacja**
   - Redukcja ρ (mniej danych),
   - wybór opcji o najmniejszym ΔS, jeśli system jest przeciążony.

6. **φ**
   - Po decyzji: φ(S) → I' (nowa informacja zwrotna).
