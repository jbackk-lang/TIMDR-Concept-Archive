# Zastosowanie: Systemy uczenia się (Learning Systems)

## Cel
Użyć topologii informacji do:
- projektowania procesów nauki,
- unikania przeciążenia,
- optymalizacji trajektorii wiedzy.

## Jednostki
- I — nowa informacja,
- S — struktura wiedzy,
- ΔS — różnica między starą a nową wiedzą,
- ρ — gęstość materiału,
- φ — konsolidacja.

## Procedura

1. **Nowa informacja jako I**
   - Każdy moduł wiedzy = Iₖ.

2. **Struktura wiedzy jako S**
   - S rośnie iteracyjnie.

3. **ΔS**
   - Zbyt duże ΔS → trudność przyswojenia.

4. **ρ**
   - Zbyt dużo materiału naraz → przeciążenie.

5. **φ**
   - Konsolidacja: φ(Sₜ) → Sₜ₊₁.

6. **Stabilny cykl nauki**
   - S↻, gdy:
     - ΔS umiarkowane,
     - ρ kontrolowane,
     - φ działa regularnie.
