# TIMDR-Concept-Archive

Archiwum 16 wcześniej osobnych repozytoriów `jbackk-lang` zawierających
**modele koncepcyjne / narzędzia do myślenia** związane z ekosystemem
TIMDR — nie kod inżynieryjny, nie zwalidowane formalizmy matematyczne
(te są w `GIA-TIMDR` i repozytoriach `TIMDR-*-Formalism`), tylko autorskie
metafory, szkice i dywagacje interpretacyjne, w większości wprost
oznaczone przez autora jako "model koncepcyjny, nie teoria naukowa ani
model empiryczny".

Każde repo trafiło tu jako podkatalog przez `git subtree add`
**z zachowaniem pełnej historii commitów** oryginału (widoczna w `git log`
jako drugi rodzic commitu importującego). Oryginalne repozytoria na
GitHubie: patrz link przy każdej pozycji niżej.

## Czym to NIE jest

Żaden z powyższych modeli nie jest zwalidowaną teorią naukową ani
zweryfikowanym formalizmem matematycznym — zdecydowana większość z nich
sama się tak opisuje wprost w swoim README. Prawdziwe, testowane
formalizmy matematyczne (aksjomaty, dowody, kod z testami) TIMDR żyją
osobno w `GIA-TIMDR` oraz `TIMDR-Math-Formalism` / `TIMDR-Geometry-Formalism`
/ `TIMDR-Modal-Formalism` / `TIMDR-Time-Formalism`. Prawdziwe, zwalidowane
projekty inżynieryjne (z testami, danymi realnymi, wynikami pozytywnymi
i negatywnymi) żyją w osobnych repozytoriach domenowych
(np. `TIMDR-Earthquake-Core`, `TIMDR-Tornado-NEXRAD`, `Synoptyk-v3` itd.)
i nie zostały tu przeniesione.
