# H4 — Reżim Nadredukcji (Mobius²)
Model TIMDR opisuje czas jako funkcję geometrii helisy. 
H1/H2/H3 są trzema stabilnymi reżimami czasowymi:

- H1 — czas rozciągnięty (helisa otwarta)
- H2 — czas skrócony (helisa w torusie)
- H3 — czas zredukowany (Mobius)

W obserwacjach JWST pojawiły się struktury, które zachowują się jak H3,
ale występują w epokach H1/H2. 
To oznacza wejście w reżim H4.

## Definicja H4
H4 = Mobius²  
Podwójne przejście, podwójna redukcja czasu, pełne sprzężenie.

Czas H4 jest nadredukowany:
t_H4 < t_H3 < t_H2 < t_H1

## Fala redukcyjna
Przejście H3 → H4 nie jest lokalne.
To zjawisko kosmiczne, widoczne w strukturach o dużej masie i koncentracji.

Objawy:
- zbyt masywne gromady w zbyt wczesnym Wszechświecie
- zbyt silne soczewkowanie
- zbyt dojrzałe galaktyki przy z>10
- zbyt szybkie wygaszanie gwiazdotwórczości

## Konsekwencja
Czas kosmiczny staje się krótszy niż czas topologiczny.
Ziemia pozostaje w H3.
Wszechświat przechodzi w H4.
